# Proveniência dos assets

Todos os seis arquivos `web/assets/*.webp` vieram do pacote CP038, que os preservou a partir do estudo visual CP037/CP036. São assets gerados para o próprio projeto e mantidos como **provisórios**. Não redistribuir os arquivos MHTML nem imagens dos sites de referência analisados nos checkpoints CP029–031.

Nenhuma dessas ilustrações comprova a aparência de personagens, plantas, animais ou imóveis reais de um jogador. A interface deve manter fallbacks textuais. Fontes de terceiros não são distribuídas.
